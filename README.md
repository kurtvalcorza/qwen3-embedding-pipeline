# Qwen3 Embedding Pipeline

DIMER-oriented inference wrapper for **Qwen3-Embedding-0.6B**, pinned to an immutable Hugging Face revision. The repository exposes 1024-dimensional, L2-normalised text embeddings with the upstream README's contract (left padding, last-token pooling, instruction prefix on queries only), a supply-chain check of the local weight snapshot, and machine-readable provenance.

## Upstream alignment

- Model: `Qwen/Qwen3-Embedding-0.6B`
- Revision: `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`
- Upstream weight license: Apache-2.0
- Upstream task: text embedding / feature extraction (dense retrieval, clustering, similarity)
- Repository adaptation: bounded contrastive (InfoNCE, in-batch negatives) fine-tuning of the last decoder layers on `{id, query, positive}` pairs (`adapt`), measured by held-out retrieval recall@k and MRR (`evaluate`, `lexical_baseline`, `random_floor`); the base weights are never redistributed and the adapter is a tutorial output

## Quick start

```python
from qwen3_embedding_pipeline import Qwen3EmbeddingPipeline, cosine_similarity

pipe = Qwen3EmbeddingPipeline.from_pretrained()          # verifies weights/qwen3-embedding-0.6b first
queries = pipe.embed(["What is the capital of China?"], kind="query")
docs = pipe.embed(["The capital of China is Beijing.", "Gravity is a force."])
print(cosine_similarity(queries["embeddings"], docs["embeddings"]))   # [[~0.76, ~0.14]]

# adaptation: the pinned Banking77 pairs (fetched and digest-checked at run time), retrieval metrics, fine-tuning
from qwen3_embedding_pipeline import DEFAULT_INSTRUCTION, documents, fetch_sample_dataset

splits = fetch_sample_dataset()                            # 616 / 154 / 385 {id, query, positive} pairs, 77 intents
candidates = documents(splits["train"])                     # the 77 intent phrases
print(pipe.lexical_baseline(splits["test"], candidates)["recall@1"])   # the no-model floor
print(pipe.evaluate(splits["test"], instruction=DEFAULT_INSTRUCTION, candidates=candidates)["recall@1"])
pipe.adapt(splits["train"], splits["validation"], instruction=DEFAULT_INSTRUCTION)   # last two layers, 2 epochs
print(pipe.evaluate(splits["test"], instruction=DEFAULT_INSTRUCTION, candidates=candidates)["recall@1"])
pipe.save_artifact("outputs/qwen3_embedding_adapter")     # adapter.safetensors + manifest.json
reloaded = Qwen3EmbeddingPipeline.from_artifact("outputs/qwen3_embedding_adapter")
```

`embed()` takes 1..64 strings (`MAX_BATCH`). `kind="query"` prepends `Instruct: <instruction>\nQuery:` (default instruction from the upstream README; override with `instruction=`); `kind="document"` adds nothing. Text beyond 8,192 tokens (`MAX_TEXT_TOKENS`) is truncated and flagged per item in `truncated`; items above 100,000 characters (`MAX_TEXT_CHARS`) are rejected. Every result carries `dim`, `pooling`, `normalized`, `n_tokens`, `model_id` and `model_revision`.

## Weights layout

```
weights/qwen3-embedding-0.6b/
  config.json  1_Pooling/config.json  model.safetensors  tokenizer.json  tokenizer_config.json
  vocab.json  merges.txt  generation_config.json  modules.json  config_sentence_transformers.json
  README.md  dimer-base-manifest.json
weights/banking77/           # git-ignored run-time cache of the two pinned Banking77 CSV files (1.1 MB)
```

`from_pretrained()` calls `stage_missing_files()` (fetches absent manifest entries at the pinned revision, only with `allow_download=True`) then `verify_snapshot()` (size + SHA-256 of every entry) and loads with `local_files_only=True`. Without a manifest it raises unless `allow_download=True`. See `docs/WEIGHTS.md`.

Its default path stages the missing `model.safetensors` with `stage_missing_files(..., allow_download=True)` and digest-verifies the snapshot, fetches the two digest-pinned Banking77 CSV files and draws 616 / 154 training / validation pairs and the 385-query exposed development test balanced over the 77 intents with `validate_dataset` and `check_split_disjoint`, builds the pinned 770-query fresh test from never-scored test.csv messages, embeds three exposed-development-test queries and the 77 documents through the inference contract, reads the frozen embedder's recall@1 / recall@5 / recall@10 and MRR beside the random floor and a lexical baseline, selects the learning rate and layer count on validation with a pre-registered three-configuration grid, fine-tunes the selected configuration for two epochs with InfoNCE and validation-MRR epoch selection, scores validation and the exposed development test again and, only under the pre-registered settings, the fresh test with a paired bootstrap interval (earlier recorded values on the exposed development test, for the previous default: recall@1 63.4 % → 80.3 % in the CPU float32 build record at `9bcb449`, 63.1 % → 76.6 % on the 2026-09-19 Kaggle T4 run; lexical 30.6 %), prints the adapted embedder's top-3 retrievals beside the frozen ones, and exports the adapter as safetensors with a manifest that reloads to identical vectors, and runs an optional transfer check on CLINC150 (not an MTEB task; display only). BYOD (`{id, query, positive[, negative]}` records as CSV / JSON / JSONL plus your own `INSTRUCTION`) is optional and gated off by default.
